# 🛒 Blinkit Sales Analysis Dashboard Using Excel

## 📌 Project Overview

This project focuses on analyzing Blinkit sales data using Microsoft Excel to identify sales trends, product performance, and business insights through an interactive dashboard.

## 🛠️ Tools Used

- 📗 Microsoft Excel
- 📊 Pivot Tables
- 📈 Charts and Data Visualization
- 🔍 Data Analysis

## 📂 Dataset

The project includes datasets related to customers, orders, products, order items, and delivery performance.

## 🎯 Project Objectives

- ✅ Analyze overall sales performance.
- ✅ Identify top-performing products.
- ✅ Understand order and delivery trends.
- ✅ Present key business insights through a dashboard.
